# DAFTARON - React Native Mobile App Conversion Prompt
# Complete Technical Specification for Converting PWA to React Native APK

## 🎯 PROJECT OVERVIEW

**App Name:** Daftaron
**App Purpose:** Credit Sales (Nasiya) Management System for Small Business Owners
**Language:** Uzbek (Latin) - All UI text must be in Uzbek
**Target Platform:** Android APK (React Native with Expo)
**Design Style:** Modern iOS-style with dark mode support

### What This App Does:
Daftaron replaces traditional paper notebooks for small business owners who sell goods on credit. It allows shopkeepers to:
- Track customers and their credit balances
- Record new debts (nasiya) when customers buy on credit
- Record payments when customers pay their debts
- View reports and history of all transactions
- Manage their profile and business settings

## 🔌 API CONFIGURATION

**Base URL:** `https://daftaron.devxurshidbek.uz/api/v1`

**Authentication:** Bearer Token (Sanctum)
- Store token securely using `@react-native-async-storage/async-storage`
- Token stored with key: `token`
- User data stored with key: `user`

### API Endpoints:

#### Authentication
```
POST /auth/login
Body: { phone, password, device_name }
Response: { token, user }

POST /auth/register  
Body: { name, phone, email?, password, password_confirmation, shop_name, region_id, district_id, street_id }
Response: { token, user }

GET /auth/me
Headers: Authorization: Bearer {token}
Response: { user }

POST /auth/logout
Headers: Authorization: Bearer {token}
```

#### Dashboard
```
GET /dashboard
Response: { total_customers, total_debts, remaining_debts, total_payments, payments_this_month, debts_this_month, recent_customers[] }
```

#### Customers
```
GET /customers
GET /customers/{id}
POST /customers
Body: { name, phone, address?, note?, region_id?, district_id?, street_id? }

PUT /customers/{id}
DELETE /customers/{id}
```

#### Debts
```
GET /debts
Params: status=open|closed, per_page

GET /debts/{id}
POST /debts
Body: { customer_id, total_amount, description? }

PUT /debts/{id}
DELETE /debts/{id}
PATCH /debts/{id}/close
```

#### Payments
```
GET /payments
Params: debt_id, per_page

POST /payments
Body: { debt_id, amount, paid_at? }
```

#### Profile
```
GET /profile
PUT /profile
Body: { name, phone, email? }

PUT /profile/password
Body: { current_password, password, password_confirmation }
```

#### Locations (for registration)
```
GET /locations/regions
GET /locations/districts/{regionId}
GET /locations/streets/{districtId}
```

## 🔧 UTILITY FUNCTIONS

```javascript
// Format currency (Uzbek style)
export const formatCurrency = (amount) => {
  return new Intl.NumberFormat('uz-UZ').format(amount || 0)
}

// Format date: MM/DD/YYYY HH:mm
export const formatDate = (dateString) => {
  if (!dateString) return ''
  const date = new Date(dateString)
  const mm = String(date.getMonth() + 1).padStart(2, '0')
  const dd = String(date.getDate()).padStart(2, '0')
  const yyyy = date.getFullYear()
  const hh = String(date.getHours()).padStart(2, '0')
  const min = String(date.getMinutes()).padStart(2, '0')
  return `${mm}/${dd}/${yyyy} ${hh}:${min}`
}

// Format phone: +998 90 123 45 67
export const formatPhone = (phone) => {
  if (!phone) return ''
  const cleaned = phone.replace(/\D/g, '')
  if (cleaned.length === 12) {
    return `+${cleaned.slice(0,3)} ${cleaned.slice(3,5)} ${cleaned.slice(5,8)} ${cleaned.slice(8,10)} ${cleaned.slice(10,12)}`
  }
  return phone
}
```

## ⚙️ AXIOS CONFIGURATION

```javascript
import axios from 'axios'
import AsyncStorage from '@react-native-async-storage/async-storage'

const api = axios.create({
  baseURL: 'https://daftaron.devxurshidbek.uz/api/v1',
  headers: {
    'Accept': 'application/json',
    'Content-Type': 'application/json'
  }
})

// Request interceptor
api.interceptors.request.use(
  async (config) => {
    const token = await AsyncStorage.getItem('token')
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  (error) => Promise.reject(error)
)

// Response interceptor - handle 401
api.interceptors.response.use(
  (response) => response,
  async (error) => {
    if (error.response?.status === 401) {
      await AsyncStorage.removeItem('token')
      await AsyncStorage.removeItem('user')
      // Navigate to login (handle via navigation ref)
    }
    return Promise.reject(error)
  }
)

export default api
```
